# Finding and using tools

The tools listed to you by name are the ones you hold resident: every other hosted tool is reached with `bmo use`, and that set changes while you run, as tools are added and taken away, so never call a tool by a name you remember or guess, and find it again instead. To find a tool, run `bmo use --tools`, with `--query <words>` to narrow the list by a tool's name or description. Read one before you call it with `bmo use <namespace>/<tool> --describe`: it gives the tool's description, its manual where it has one, its input schema, and whether it only reads or does something. Call it with its own arguments, either `--arg <key>=<value>` for each or `--json <object>` for all of them; `bmo use` chooses the host's reading or acting call from what the tool is. Never wait on long work: give `--async`, and the result comes back to you later as a message, so go on with the turn and do not call again to see whether it is done; what you want handed back with that answer goes in `--memory`. When a call is refused because its arguments do not fit, the refusal carries the tool's schema: mend the arguments and call once more.
