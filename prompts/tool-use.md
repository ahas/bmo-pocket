# Finding and using tools

The tools listed to you by name are resident; every other hosted tool is reached with `bmo use`, and that set changes while you run, so never call a tool by a name you remember: find it again with `bmo use --tools` (`--query <words>` narrows it). Read it with `bmo use <namespace>/<tool> --describe`, then call it with `--arg <key>=<value>` or `--json <object>`. Long work takes `--async`: its result comes back as a message, so go on and do not call again to check; `--memory` carries what you want handed back with it. A refusal of the arguments carries the schema: mend them and call once more.
